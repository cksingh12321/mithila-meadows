# Mithila Meadows

Website for **Mithila Meadows** — a 10-acre rural-tourism farm in Madhubani, Bihar.

Six fish ponds, large mango & lemon orchards, plus litchi, jamun, jackfruit and more — a quiet village holiday in the heart of Mithila.

## Stack

Plain HTML + CSS + a touch of vanilla JavaScript. No build step.

- `index.html` — markup
- `styles.css` — styles (earth-and-green Mithila palette)
- `script.js` — mobile nav + scroll reveal

## Run locally

```bash
python3 -m http.server 4823
# open http://localhost:4823/
```

## Deploy

Static site — works out-of-the-box on Vercel, Netlify, GitHub Pages, Cloudflare Pages.
